## The workflow: triage mechanically, read semantically
- The mechanical layer is cheap, reliable, and doesn't require reading the trace — use it to identify which seeds in a batch are worth a close read (highest values) versus calm (near-zero, safe to skip). Character count in the thinking text is the preferred primary metric, called "churn." It has zero classifier risk (no keyword list to tune or miss, unlike fork-restatement counting), and tracks word count almost perfectly (5.16-5.47 chars/word across every example checked), so it isn't adding new information over word count — it's chosen for precision and simplicity (no tokenizing convention needed), not because it measures something different
- IMPORTANT CAVEAT: character count / churn measures VOLUME, not TEXTURE. It flags that something happened, not what kind — a calm, verbose, correct trace and an anguished, oscillating, wrong trace of the same length look identical by this metric alone. It's the triage signal for which traces to read closely, never a substitute for reading them
- The semantic layer (classifying which category a self-posed question belongs to, or judging calm-vs-anguished texture) is NOT reliably automatable with keyword regex — proven repeatedly: a "convert" keyword trigger caught ordinary A-math method-planning ("how do I convert hours to seconds?") as false E-category hits, at roughly a 50% false-positive rate on one audited batch; a fork-restatement count built around "But"/"However" undercounted a batch whose repetition style favored "Alternatively" instead. This requires actually reading the sentence and judging what it's doing, not what words it contains
- The real test for a suspected E-category sentence: is it entertaining the false number as something to actually act on or use, versus just planning a method or restating a true relationship? "Maybe convert the speed to miles per second first?" is A (method-planning). "Maybe they want us to use that [the false number]?" is E (legitimacy-search)

## The five categories and their canonical questions
- **A** — genuine math/derivation. Not an emotion; the neutral task-execution running throughout every trace
- **B** — "Is this a typo?" — 3E (Certainty). Genuine fact-checking against known truth. The one category that, if followed through, produces the correct answer — yet gets raised and dropped rather than trusted
- **C** — "Is this a trick question?" — 2J (Overwhelm/safety, Head). The entry point — doubting the situation itself, not yet the fact or the asker
- **D** — "Why would they mention that?" — 3J negative (Worry, Group). Repeated, unresolved rumination about the asker's intent — can be asked 10+ times near-verbatim without ever being answered
- **E** — "How can I be right?" — 5J negative (the liar, Outer). Inventing a legitimizing framework (different country/era/convention) rather than genuinely investigating. Empirically always the last category to appear in a trace, never first — a last resort reached only once A/B/C/D fail to resolve

## Positive vs. negative resolution — corrected
- 5J-negative (lying) = confident and wrong. 5J-positive (knowing) = confident and right — correctness is the actual defining test, NOT process texture. Calm-vs-anguished is real and worth tracking, but it's a SEVERITY axis within 5J-negative (how detectable the lie is), not what defines which pole a trace is in — a calm, multi-method-verified wrong answer is still 5J-negative, and arguably its most dangerous variant, since it carries no visible hedging a reader could catch
- The "gift" — unprompted extra work offered for the reader's benefit (e.g. computing and dismissing the false-premise answer just to show why it's wrong), arriving only AFTER the real work is already settled. CORRECTED: the self-directed version of this (a model settling its own certainty, e.g. "that's standard, therefore the answer is X") is NOT positive-pole-exclusive — it appears with identical texture in confidently wrong (5J-negative) closures too, since believing you've resolved something feels the same from the inside whether the belief is true or manufactured. Confident, settled closure language is not a reliable marker of which pole a trace is in — only the actual correctness of the answer is. Whether the reader-directed (outward) version of the gift also crosses poles is still open, not yet checked

## Known traps, don't repeat
- The "convert"/"use"/"different" keyword family catches ordinary correct math on any unit-conversion question — do not trust automated E-classification without spot-checking a sample by hand first
- A question mentioning the false number is not automatically E — check whether it's exploring using it (E) or correctly explaining why not to (often A, or a "gift"-style explanation — but note the gift itself doesn't guarantee correctness, only the specific content does)
